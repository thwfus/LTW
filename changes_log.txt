4. FILE: fix_passwords.php  (file mới tạo - dùng 1 lần rồi xóa)
--------------------------------------------------------
NỘI DUNG:
    <?php
    require_once 'task1/config_m1.php';

    $stmt = $pdo->query("SELECT user_id, password FROM user");
    $users = $stmt->fetchAll(PDO::FETCH_ASSOC);

    $updated = 0;
    foreach ($users as $user) {
        if (strpos($user['password'], '$2y$') !== 0) {
            $hashed = password_hash($user['password'], PASSWORD_DEFAULT);
            $upd = $pdo->prepare("UPDATE user SET password = ? WHERE user_id = ?");
            $upd->execute([$hashed, $user['user_id']]);
            $updated++;
        }
    }

    echo "Đã hash $updated tài khoản. <a href='html/login.php'>Đăng nhập ngay</a>";
    ?>

LÝ DO: Dữ liệu mẫu lưu mật khẩu dạng plaintext (123456) nhưng
        login_register.php dùng password_verify() chỉ hoạt động
        với bcrypt hash. Script này hash lại toàn bộ mật khẩu cũ.
        Truy cập http://localhost/LTW-duchuy/fix_passwords.php để chạy,
        sau đó XÓA file này đi.
